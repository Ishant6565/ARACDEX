## ✨ Features

- 🎮 **13 Full Arcade Games:**
  1. **Snake Cyber** (100 Speedrun Stages with Obstacles & Speed Scaling)
  2. **Tetris Monolith** (100 Gravity Tiers with Ghost Piece & Instant Hard Drops)
  3. **2048 Synth-Grid** (100 Synthesis Targets with Smooth Grid Physics)
  4. **Anime Jigsaw** (100 Sliced Levels with 22 Iconic Anime Titans: Gojo, Kakashi, Naruto, Sukuna, Levi, etc.)
  5. **Sudoku Monolith** (100 Curated Puzzles from Beginner to Grandmaster with Candidates)
  6. **Wordle Cipher** (100 5-Letter Ciphers with Context Clues & Sentences)
  7. **Memory Glyphs** (100 Spatial Matching Tiers with Minimalist Glyphs)
  8. **Simon Rhythm** (100 Harmonic Synthesizer Sequence Stages)
  9. **Chimp Memory** (100 Primate Working Memory Spatial Masking Milestones)
  10. **Corsi Blocks** (100 Neuropsychological Visuo-Spatial Span Challenges)
  11. **Connect 4** (100 Tactical Bot Duels with Strategic Minimax AI)
  12. **15-Puzzle Classic** (100 Scramble Matrix Tiers with Move Quotas)
  13. **Arrow Escape** (Dynamic Multi-Directional Untangle Puzzle)

- ⚡ **100 Progressive Levels Per Game:** Full level select drawer, score tracking, and auto-save checkpoints.
- 📱 **Progressive Web App (PWA):** Installable on Android, iOS, Windows, and macOS with 100% offline gameplay via Service Worker.
- 🔊 **Native Web Audio Synthesizer:** Real-time polyphonic audio feedback and procedural chords without external sound asset latency.
- 🎨 **Midnight Editorial Aesthetics:** Pure black canvas (`#050505`), Electric Cyan accents, sleek micro-animations, and 60 FPS GPU-accelerated transforms.
- 🛡️ **Zero Cloud Dependency & Instant Sync:** Complete local-first execution with local roster accounts, custom IDs, and seamless Google Account integration.

## 🚀 Instant Deployment (Vercel)

ARCADEX is pre-configured with `vercel.json` for 1-click zero-config deployment:

```bash
# 1. Clone repository
git clone https://github.com/Ishant6565/ARACDEX.git
cd ARACDEX

# 2. Install dependencies
npm install

# 3. Build & Preview
npm run build
npm run preview
```

### Vercel Project Settings
- **Framework Preset:** `Vite`
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`
